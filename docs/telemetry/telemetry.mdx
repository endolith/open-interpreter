Open Interpreter contains an optional telemetry feature that can send **anonymous** usage information to a third-party analytics service.

**Telemetry is disabled by default.** It is a legacy feature from the original Python project. If you enable it, events may still be sent to the PostHog project configured in the code, but this community-maintained fork does not depend on that data.

# Opting in

If you still want to enable telemetry, you can do this in several ways.

### Python

Set `disable_telemetry` to `false` on the `interpreter` object:

```python
from interpreter import interpreter
interpreter.disable_telemetry = False
```

### Terminal

Use the `--no-disable_telemetry` flag:

```shell
interpreter --no-disable_telemetry
```

### Profile

Set `disable_telemetry` to `false`. This will persist to future terminal sessions:

```yaml
disable_telemetry: false
```

### Environment Variables

Set `ENABLE_TELEMETRY` to `true` in your shell or server environment.

If you are running Open Interpreter on your local computer with `docker-compose` you can set this value in an `.env` file placed in the same directory as the `docker-compose.yml` file:

```
ENABLE_TELEMETRY=true
```

# Opting out

Telemetry is already off by default. You can also force it off explicitly:

```python
interpreter.disable_telemetry = True
```

```shell
interpreter --disable_telemetry
```

```yaml
disable_telemetry: true
```

```
DISABLE_TELEMETRY=true
```

# What is sent?

If telemetry is enabled, Open Interpreter may send anonymous events such as:

- Open Interpreter version and environment (i.e whether or not it's running in Python / a terminal)
- When interpreter.chat is run, in what mode (e.g `--os` mode), and the type of the message being passed in (e.g `None`, `str`, or `list`)
- Exceptions that occur within Open Interpreter (not tracebacks)

It does **not** collect personally-identifiable or sensitive information, such as: usernames, hostnames, file names, environment variables, or hostnames of systems being tested.

To view the list of events that may be sent, see the **[code](https://github.com/endolith/open-interpreter/tree/main/interpreter/core)**

## Where may telemetry be sent?

If enabled, events are posted to **[PostHog](https://posthog.com/)** using a project key embedded in the source code (from the original project).
