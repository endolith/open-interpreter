# Telemetry has been removed

Open Interpreter no longer collects any usage information. There is nothing to opt out of.

Earlier versions posted anonymous usage events to a third-party analytics service (PostHog) hosted by the project's previous maintainers. Since this repository is no longer maintained by them, continuing to send usage data there would mean shipping it to an organization whose maintainers cannot see or delete it. The collector has been removed from the codebase rather than left in place behind a flag, so no code path remains that could send anything.

Open Interpreter itself no longer collects anything about your usage and sends no telemetry or conversation contributions anywhere. There is nothing to opt out of. Requests to a configured remote model still send conversation data to that provider, as any LLM client must. The hosted `i` model and the conversation-contribution feature were removed for the same reason: they posted your conversations to `api.openinterpreter.com`, which no longer serves either.

## What this means for existing configuration

The Python setting and profile key are no longer read, and leaving them in place has no effect. The CLI flag is no longer recognized; retaining it prints an unrecognized-argument message and exits with status 1.

### Python

```python
# No longer supported — remove this line
interpreter.disable_telemetry = True
```

### Terminal

```shell
# No longer recognized; remove from scripts and aliases
interpreter --disable_telemetry
```

### Profile

```yaml
# No longer recognized; remove from your profile files
disable_telemetry: true
```

### Environment variables

`DISABLE_TELEMETRY` is no longer read.

## What was collected, for the record

The removed feature recorded: the Open Interpreter version; whether a session was running in the terminal interface or in Python; whether OS mode was active; the *type* of a message passed to `interpreter.chat` (e.g. `str` or `list`, never its content); and exception messages raised inside Open Interpreter. It did not collect message content, file names, usernames, or environment variables.

Each install was identified by a random UUID stored at `~/.cache/open-interpreter/telemetry_user_id`. That file is no longer written and can be deleted.

## Remaining network use

Open Interpreter still contacts the network for the language model you configure, and for a PyPI version check on startup. `--offline` disables the version check and the update prompts.
