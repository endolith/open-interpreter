To use Qwen and other models on [Alibaba Cloud DashScope](https://www.alibabacloud.com/help/en/model-studio/getting-started/models), set the `model` flag with a **region prefix**:

| Prefix | Region | API base (set automatically) |
| ------ | ------ | ------------------------------ |
| `dashscope-us/` | US (Virginia) | `https://dashscope-us.aliyuncs.com/compatible-mode/v1` |
| `dashscope-intl/` | International (Singapore) | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` |

<CodeGroup>

```bash Terminal
interpreter --model dashscope-us/qwen3.5-plus
```

```python Python
from interpreter import interpreter

interpreter.llm.model = "dashscope-us/qwen3.5-plus"
interpreter.chat()
```

</CodeGroup>

Open Interpreter routes these slugs to DashScope's OpenAI-compatible endpoint: it sends the bare model id over the OpenAI protocol with the region's base URL, because LiteLLM has no provider for the region prefix. The model name you set stays what the interpreter reports, and it is the name used for metadata lookups (tool and vision support, context window).

# Supported Models

Use any model id listed in the [DashScope model catalog](https://www.alibabacloud.com/help/en/model-studio/getting-started/models). Examples:

<CodeGroup>

```bash Terminal
interpreter --model dashscope-us/qwen3.5-plus
interpreter --model dashscope-us/qwen3-max
interpreter --model dashscope-intl/qwen3.5-plus
interpreter --model dashscope-intl/qwen3-max
```

```python Python
interpreter.llm.model = "dashscope-us/qwen3.5-plus"
interpreter.llm.model = "dashscope-us/qwen3-max"
interpreter.llm.model = "dashscope-intl/qwen3.5-plus"
interpreter.llm.model = "dashscope-intl/qwen3-max"
```

</CodeGroup>

Pick `dashscope-us/` or `dashscope-intl/` based on where your API key is provisioned and which region you want to call.

# Thinking

Qwen 3.5 and later think by default. Open Interpreter's portable reasoning settings are translated to DashScope's own fields instead of being sent as OpenAI parameters:

| Setting | DashScope field |
| ------- | --------------- |
| `include_reasoning = False` | `enable_thinking: false` |
| `reasoning_effort = 4096` (integer) | `enable_thinking: true` + `thinking_budget: 4096` |
| prior reasoning in the conversation | `preserve_thinking: true` |

```python Python
interpreter.llm.include_reasoning = False   # disable thinking
interpreter.llm.reasoning_effort = 4096     # token budget
```

The integer is a token budget in DashScope's own unit. A level name such as `"high"` enables thinking but is not converted into a budget, because DashScope does not document that mapping.

# Required Environment Variables

Set the following environment variables [(click here to learn how)](https://chat.openai.com/share/1062cdd8-62a1-4aa8-8ec9-eca45645971a) to use these models.

| Environment Variable | Description | Where to Find |
| -------------------- | ----------- | ------------- |
| `DASHSCOPE_API_KEY` | API key for DashScope compatible-mode. | [Alibaba Cloud Model Studio](https://www.alibabacloud.com/help/en/model-studio/get-api-key) |

You can override the base URL manually if needed:

```python
interpreter.llm.api_base = "https://dashscope-us.aliyuncs.com/compatible-mode/v1"
```

# Vision

Qwen 3.5 models (`qwen3.5*`) support image input. When you use a `dashscope-us/` or `dashscope-intl/` slug with a Qwen 3.5 model id, Open Interpreter enables vision automatically.
