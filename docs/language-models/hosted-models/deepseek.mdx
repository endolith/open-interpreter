To use a model from the [DeepSeek API](https://platform.deepseek.com/), set the `model` flag to begin with `deepseek/`:

<CodeGroup>

```bash Terminal
interpreter --model deepseek/deepseek-flash
```

```python Python
from interpreter import interpreter

interpreter.llm.model = "deepseek/deepseek-flash"
interpreter.chat()
```

</CodeGroup>

# Supported Models

We support any model exposed by the DeepSeek API via [LiteLLM](https://docs.litellm.ai/docs/providers/deepseek). Common models include:

<CodeGroup>

```bash Terminal
interpreter --model deepseek/deepseek-flash
interpreter --model deepseek/deepseek-v4-pro
```

```python Python
interpreter.llm.model = "deepseek/deepseek-flash"
interpreter.llm.model = "deepseek/deepseek-v4-pro"
```

</CodeGroup>

See the [DeepSeek API docs](https://api-docs.deepseek.com/) for the current model list and capabilities.

Model ids are used exactly as DeepSeek publishes them. The suffix is not uniform — `deepseek-flash` has none, `deepseek-v4-pro` does — so copy an id rather than deriving one from the other.

# Required Environment Variables

Set the following environment variables [(click here to learn how)](https://chat.openai.com/share/1062cdd8-62a1-4aa8-8ec9-eca45645971a) to use these models.

| Environment Variable | Description | Where to Find |
| -------------------- | ----------- | ------------- |
| `DEEPSEEK_API_KEY` | API key for the DeepSeek platform. | [DeepSeek API keys](https://platform.deepseek.com/api_keys) |
| `DEEPSEEK_API_BASE` | Optional. API base URL (default: `https://api.deepseek.com/beta`). | [DeepSeek API docs](https://api-docs.deepseek.com/) |

# Reasoning / thinking mode

Thinking models stream reasoning tokens when supported. Control the effort on `interpreter.llm` or in a profile:

```python
interpreter.llm.reasoning_effort = "high"  # LiteLLM enables thinking; it does not forward the effort level
```

```yaml Profile
version: 0.2.5
llm:
  reasoning_effort: "low"   # LiteLLM enables thinking but does not forward low/high/max
```

In thinking mode, DeepSeek requires prior assistant `reasoning_content` in requests with tools. Open Interpreter fills missing fields, but trimming can remove the original reasoning and leave a `.` placeholder on a tool call. The follow-up request can fail with HTTP 400. DeepSeek ignores prior reasoning history in tool-free requests.
